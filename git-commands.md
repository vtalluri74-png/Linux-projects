# Git Commands and Their Purpose

1. `git init` — Create a local Git repository.
2. `git add .` — Stage project files for commit.
3. `git commit -m "Initial commit"` — Save a snapshot locally.
4. `git remote add origin <GitHub-URL>` — Connect the local repository to GitHub.
5. `git push -u origin main` — Upload commits to GitHub and set the upstream branch.

## Future Updates

* `git status` — Check file changes.
* `git add .` — Stage changes.
* `git commit -m "Updated notes"` — Save changes locally.
* `git push` — Upload commits to GitHub.
